# notes-app
Note taking web app made using React with Typescript and TailwindCSS for the frontend, PHP and MySQL for the backend. 

## App features
* Create, read, update, and delete notes
* Archive notes
* View all the notes
* View all archived notes
* View notes with specific tags
* Search notes by title, tag, and content
* Select the notes color and font theme
* Validation messages if required form fields aren't completed
* Optimal layout for the interface depending on the user device screen size
* Full user authentication: account creation, log in, log out
* User password resetting

## How to run locally
1. Download the project from this GitHub page.
2. [Node.js](https://nodejs.org) is required in order to run ```npm install```, which will install all the packages the project needs to work.
3. Run ```npm run dev``` in the /frontend folder and it will start at "https://localhost:some-port-number".
4. Run ```php -S localhost:8000``` in the /backend folder
